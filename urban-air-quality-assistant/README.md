# Urban Air Quality Assistant

An open-source, lightweight web application designed to help users check real-time Air Quality Index (AQI) for any city and receive immediate health recommendations.

## Features
- **Real-time Data:** Fetches live data using the World Air Quality Index (AQICN) API.
- **Health Recommendations:** Provides tailored advice based on the current AQI level.
- **Accessible:** Built with semantic HTML and ARIA attributes for screen reader compatibility.
- **Responsive:** Works flawlessly on mobile and desktop devices.
- **Clean Codebase:** Vanilla HTML, CSS, and JavaScript. No heavy frameworks.

## How to use
1. Clone the repository.
2. Get a free API token from [AQICN](https://aqicn.org/api/).
3. Open `script.js` and replace `YOUR_API_KEY_HERE` with your token.
4. Open `index.html` in your browser.
